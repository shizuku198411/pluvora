# Security Policy

## Supported Versions

Pluvora is under active early-stage development and does not currently publish stable or supported releases. Security fixes are applied to the latest development branch.

## Reporting a Vulnerability

Do not report security vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting feature for this repository when available. Include:

- A description of the vulnerability and its impact
- The affected component, revision, or configuration
- Steps or proof of concept required to reproduce it
- Any suggested mitigation
- Whether the report may be publicly credited

Please avoid accessing data that does not belong to you, disrupting systems, or performing destructive testing.

The maintainers will acknowledge a report when possible, investigate it, and coordinate disclosure after a fix or mitigation is available. Response and remediation timelines cannot be guaranteed while the project remains pre-release.

## Security Scope

The intended security model is documented in the [Kernel Design Policy](docs/design/kernel-policy.md). Reports about behavior explicitly listed as out of scope are still welcome when they identify an unexpected or preventable risk.
